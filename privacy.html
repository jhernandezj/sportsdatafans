Privacy Policy

Effective 5 November 2026

This policy explains how Sports Data Fans Publisher (the "API Client"), the private tool used to run the YouTube channel Sports Data Fans, and this website handle information. Sports Data Fans is run by an independent creator based in Spain.

YouTube API Services

The API Client uses YouTube API Services (the YouTube Data API and the YouTube Analytics API). By using the API Client you agree to be bound by the YouTube Terms of Service. Information obtained through YouTube API Services is also subject to the Google Privacy Policy (http://www.google.com/policies/privacy).

Who uses the API Client

The API Client is not a public app. It runs on the channel owner's own computer, and the only person who signs in to it with a Google account is the owner of the Sports Data Fans channel. It never asks other people to sign in and never accesses data of other YouTube users or channels.

What information the API Client accesses

When the channel owner authorises it with Google OAuth, the API Client accesses, for the Sports Data Fans channel only:

InformationWhy
The channel's name and IDTo confirm that the right channel was authorised.
The channel's own videos: their ID, privacy and publishing status, and scheduled publish timeTo upload and schedule the channel's videos and to check that they were published.
The channel's own playlistsTo create the channel's playlists and add each video to them.
The channel's own YouTube Analytics reports (aggregated views, watch time, average view duration, likes, shares, subscribers gained and lost, per video)To decide which kinds of videos to make next.

The API Client does not access comments, messages, subscribers' identities, other channels, or any personal information of viewers. YouTube Analytics data is aggregated by YouTube and does not identify viewers.

How the information is stored

  • Google authorisation (OAuth tokens). Stored only on the channel owner's computer, in a file readable only by the owner's user account. They are never stored in a code repository or sent anywhere except to Google to obtain access.
  • Video and playlist IDs and publishing status. Stored on the owner's computer to know which videos are already published.
  • Analytics reports. Stored on the owner's computer for at most 30 days; older reports are deleted automatically each time a new report is made.

How the information is shared

Information obtained through YouTube API Services is not sold, rented or shared with any third party and is not used for advertising. The only place it leaves the owner's computer is a private notification sent to the channel owner's own Telegram account (for example "video published" or a weekly summary of the channel's views); nobody else receives these messages.

Cookies and this website

The API Client does not use cookies and does not store, access or collect information on any user's device or browser. This website does not use cookies, analytics or trackers. It is hosted on GitHub Pages, which may log visitors' IP addresses for security, as described in the GitHub Privacy Statement.

Revoking access and deleting data

The channel owner can revoke the API Client's access at any time from the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, the API Client stops working and its stored tokens become useless; the owner then deletes the stored tokens, analytics reports and publishing records from the computer. Anyone who believes the API Client holds information about them can ask for it to be deleted using the contact below, and it will be deleted within 7 days.

Changes

If this policy changes, the new version will be published on this page with a new effective date.

Contact

Questions about this policy or about the channel: open an issue at github.com/jhernandezj/sportsdatafans/issues or write through the channel's About page.
